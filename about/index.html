One‑line ZenSkin install (Debian/Ubuntu)

wget -O zenskin.deb https://github.com/bhuvanesh-m-dev/zenskin/releases/download/zenskin-v1.deb/zenskin-v1.deb && sudo dpkg -i zenskin.deb || (sudo apt --fix-broken install -y && sudo dpkg -i zenskin.deb) && zenskin

After installation, launch zenskin to transform your theme, install PyLlamaUI, Setbian modules & AI tools interactively.
